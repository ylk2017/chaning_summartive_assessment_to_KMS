Two-file Tool：由 26-27 6S marks 自動填入 5S Ch test result 空白位

載入 source workbook 和 target workbook，從 1st / 2nd / 3rd assessment 抽取每位學生在五本書不同 chapter 的表現，然後一鍵輸出填好空白的新 Excel。

一、選擇兩個 Excel 檔案

Source：26-27 6S marks.xlsx
Target：5S Ch test result (25-26).xlsx
工具會用 source 的 assessment item-level data summarize，再填入 target 的空白 / ?? / NA cells。

必須包含 1st assessment、2nd assessment、3rd assessment sheets。

程式會在 target workbook 中自動尋找有 Class / Number / Name 的 sheet。

Source sheet 設定

如 source workbook 的 assessment sheet 名稱不同，可在這裡修改，用 comma 分隔。

預設不會使用 daily marks。只有勾選下面「同時用 daily marks 補充」才會用。

Target sheet 設定

如果 target workbook 有很多 unrelated sheets，可以在這裡指定要填的 sheet 名稱。

二、填入選項

通常建議用 Raw score。如果 target column 的 full mark 固定而 source chapter full mark 不同，可改用 scale。

例如 Book 4 Circuit 可 compatible 到 power / domestic electricity，但 exact first 較安全。

如果 target header 有明確寫 1st / 2nd / 3rd，會優先跟 target header。

基本勾選項

包括 MCQ
MCQ 會用 answer key 自動改分：答中 = full mark，答錯 = 0。
包括 SQ
SQ 直接讀 item score。
忽略整條 item column 沒有任何學生資料的題目
對 2nd assessment 這類沒有逐題 MCQ answer 的 sheet 特別重要，避免把空白 MCQ 題目計入 full mark。
同時用 6S / 5S daily marks 補充
預設不勾。若你想同時填例如 Radioactivity Ch 2 supp exe，可勾選。
ABS / absent 當作 0 分
預設不勾。若不勾，缺席學生不會填分，只會在 audit 標記。
MCQ 的 ? / ?? 當作答錯
對 assessment MCQ answer 欄常見的 ?，一般當 0 分處理。
個別 MCQ blank 當作答錯
若整條 MCQ item column 全部學生都是 blank，仍會被「無學生資料」規則跳過。
覆蓋已有數值 / 公式
預設不勾。一般只填 target 的 blank / ?? / NA。除非你很確定，否則不要勾。

Target 填入範圍

填學生分數 cells
對每位學生按姓名配對後填入 target column。
填 Full / Full mark row
若 target 有 Full row 且該 cell 空白，會填 source chapter full mark。
填 average / max / min / pass % rows
預設不勾。若勾選，會根據填入後的學生分數計算。Pass % 以 50% 為 pass threshold。
保留 detailed chapter
例如 Book 2 Projectile motion 和 Book 2 Circular motion 分開計。
建議流程： 第一次不要勾 覆蓋已有數值 / 公式，先生成 filled Excel 和 audit CSV，確認 mapping 正確後再正式使用。

三、Mapping / Normalisation 設定

Student alias mapping

格式：target name => source assessment name。如果 target 用新名，source assessment 用舊名，可在這裡補充。

Target column manual mapping

格式：target keyword => source sheet | source chapter。
可用 * 表示 source chapter 由 target column header / Book row 自動判斷。
例如：1st assessment => 1st assessment | *

Chapter normalisation rules

格式：keyword => normalised chapter。程式會大小寫不敏感 matching，較長 keyword 會優先。

尚未讀取檔案。

四、下載結果

建議先開 fill_audit.csv 和 target_column_mapping.csv 檢查每一欄是否 map 到正確 assessment / chapter。

五、Target Column Mapping Preview

顯示 target 每一個 column 被推斷要由 source 哪一個 assessment / chapter 填。只顯示前 160 行。

六、Fill Audit Preview

顯示填入 / 跳過 / unmatched cells 的紀錄。只顯示前 220 行。

七、Source Chapter Summary Preview

從 source assessment 抽取後，每個學生 × assessment × chapter 的 summary。只顯示前 160 行。

八、Source Item Audit Preview

顯示 source 每一條 item column 如何被分類。只顯示前 160 行。
